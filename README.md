# 🐶 FlyingCheems

> A Flappy Bird-inspired Java game featuring the iconic Cheems meme character.

---

## 🎮 About

FlyingCheems is a fun, meme-themed clone of Flappy Bird built entirely in Java. Guide Cheems through an endless obstacle course — tap to fly, dodge everything, survive as long as you can.

---

## 🗂️ Project Structure

```
FlyingCheems/
└── FLYINGCHEEMS/
    └── FlyingCheems.java   # Main game file (rendering, physics, input, collision)
```

---

## 🚀 Setup & Run

### Prerequisites
- Java JDK 8+

### Compile & Run

```bash
cd FLYINGCHEEMS
javac FlyingCheems.java
java FlyingCheems
```

---

## 🕹️ Controls

| Key | Action |
|---|---|
| `Space` / `Click` | Flap up |
| `ESC` | Quit |

---

## 🛠️ Tech Stack

- **Language:** Java
- **GUI:** Java AWT / Swing
- **Graphics:** Custom 2D rendering via `Graphics` / `paintComponent`
